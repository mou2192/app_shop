# دفتر ديون الدكان

تطبيق عربي محلي لإدارة العملاء والفواتير والأصناف وسندات القبض.

## المزايا

- يعمل بدون API وبدون تسجيل دخول.
- يحفظ العملاء والفواتير والأصناف في ذاكرة المتصفح `localStorage`.
- إضافة فاتورة بعدة أصناف، مع السعر والكمية ومجموع الأصناف والحساب السابق والمتبقي.
- إنشاء سند قبض، وإظهار المبلغ المستلم والمتبقي على العميل.
- ملف مستقل لكل عميل يعرض رصيده وفواتيره وإمكانية تعديلها.
- إرسال تفاصيل الفاتورة أو السند إلى رقم العميل في واتساب بدون الاعتماد على رابط خارجي.
- حفظ نسخة احتياطية JSON واسترجاعها.
- PWA قابلة للإضافة إلى شاشة الجوال مع الأيقونة المرفقة.

## التشغيل

```bash
pnpm install
pnpm dev
```

لنسخة الإنتاج:

```bash
pnpm check
pnpm build
```

بعد نشر مجلد `dist/public` على استضافة HTTPS، افتح الرابط من Chrome واختر **إضافة إلى الشاشة الرئيسية**.

> البيانات محلية على الجهاز نفسه. إذا حُذفت بيانات المتصفح أو تم تغيير الجهاز، استخدم زر **حفظ ملف** للاحتفاظ بنسخة احتياطية ثم **استرجاع** على الجهاز الجديد.
